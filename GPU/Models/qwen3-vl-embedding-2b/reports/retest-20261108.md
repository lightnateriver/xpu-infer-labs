# 公开交接代码重测 · 2026-11-08

单张 RTX 5090 对比单张 Ascend 910B1。运行的是本目录交付的 runtime 与 benchmark，34 项源文件哈希均与实际测试副本一致。
模型权重、视频来源/顺序、帧数、SHA256 和冻结精度参考保持不变。两组各 64 条、独立 warmup 16 条；每个 CPU worker 的真实视频 barrier、模型预热、每组完整预热后计时三轮。prefix/MM cache 关闭，无 Profiler。

合并吞吐=128÷（两组中位耗时之和），不是另测 128 并发。
本轮 GPU CPU32 是 CPU8 的 **2.5528 倍**；稳定 NPU 是 GPU32 的 **102.20%**；SPG 是 GPU32 的 **114.79%**，比稳定 NPU 吞吐高 **12.32%**。
GPU 的历史 128 条基准 3.0687 倍与本轮两组 64 条 2.5528 倍属于不同输入/批次协议，均保留原口径。
之前 SPG/GPU 的 108.42% 属历史控制；114.79% 是本轮重测，代码没有额外提速。不要把测量轮次变化算作新增算法收益。

GPU 仍是原两遍解码，NPU 为单遍；比例反映完整部署管线。只选中卡预检空闲，GPU 主机其他卡有任务，CPU/内存未隔离。三轮结果不是长期 SLA 或纯芯片算力比较。

## 精度

冻结 GPU query 与冻结旧 GPU gallery 均不替换。以下完整拼接两组后计算，128×127=16,256 个有向非自身比较；不是把两个组内计数相加。

|---|---:|---|---|---|---|
| gpu8 | 0.999846087 | 0 / 0 / 0 | 0 / 0 / 0 | 12 / 12 / 12 | 否 |
| gpu32 | 0.999846087 | 0 / 0 / 0 | 0 / 1 / 1 | 12 / 13 / 13 | 否 |

| npu-spg | 0.999008029 | 0 / 0 / 0 | 15 / 15 / 15 | 7 / 7 / 7 | 是 |

稳定 NPU 全部向量与原 NPU 参考逐字节一致，新增坐标差 0。
SPG 最大新增单维坐标差 0.0071024001；同输入最低余弦 0.999008029，三轮全部通过 ≥0.99，但旧库跨线仍为 15，相对稳定 NPU 改变 7 个判定。
GPU CPU32 也出现了重复轮数值变化和 1 个近阈值跨线，说明并发/动态批次本身不能保证浮点逐元素一致。
没有语义标签，跨线是判定差异，不是误判率。**若要求旧库 0.99 阈值零跨线，NPU 稳定版和 SPG 均未通过。**

## 输入边界与像素差异

所有配置的 128 条帧索引、尺寸、prompt token SHA256 合同一致，并通过原冻结合同检查。
GPU8/GPU32 的预处理像素＋metadata 哈希互相一致，稳定 NPU/SPG 也互相一致。
跨 x86 GPU 主机 / ARM NPU 主机，125/128 条的该组合哈希不同，不能声称两个后端输入像素逐字节一致。

补充抽查四条：metadata 与解码后未缩放的首帧 RGB 均一致；其中三条相同首帧经过 resize 后出现最大 1 灰度级差。
四条完整预处理张量的差异数分别为 50/37/35/56（各约 885万/885万/885万/1106万元素），最大绝对差均为 1。
这确认了部分跨架构 resize 舍入差异；没有核算全 128 条像素最大误差，也不将全部模型误差归因到 resize。
本次稳定 NPU 与原参考字节相同，因此这些跨架构边界不是此次整理代码造成的新回归。

## 验证与复现

- GPU CPU 测试：3 个 payload 错误守卫、3 个非法向量守卫通过。
- NPU CPU 测试：上述守卫、8 个帧数/损坏/尺寸/空视频案例、真实合成 H.264 单/两遍精确对照、18 组 C++/NumPy RGB 精确对照通过。
- SPG 实际捕获 116 次、重放 15,312 次，PIECEWISE 生效；57 处 FP32 Norm 已安装，EngineCore 前后 Torch=1。较长 token bucket 未据此验收。
- 两组本来不重叠，但已经反复参与评估，不称为新的独立盲测。
- 启动前 GPU 占用瞬时检查、私有清单导出路径和一次清单尚未就绪导致的失败，均发生在模型计时前。修复后四个配置完整结束；失败尝试未纳入中位数。
- GPU 选中卡已释放；NPU controller 完成并退出，容器停止、NPU0 无运行进程。私有完整日志/向量保留，公开只交付聚合。
