# 性能、精度与优化决策 · 2026-11-10

以下来自已完成实验记录的脱敏聚合，不将发布准备或CPU静态测试称为新增硬件benchmark。
同100条物理MP4，10个来源，总长323.296秒，0.68–13.52秒/条，720P–4K，
H.264 High 4:4:4 Predictive/gbrp、无损RGB、无音频。不是完整线上混合编码长视频分布。

## 整机流水线性能

| 配置 | 100条耗时 | 吞吐 |
|---|---:|---:|
| GPU RTX5090 原始串行 | 240.751 s | 0.415 clip/s |
| GPU RTX5090 已测最佳CPU4 / decoder2 / FIFO | 53.200 s | 1.880 clip/s |
| NPU910B1 原CPU8 / decoder2 / FIFO，精简ABBA对照中位 | 47.246 s | 2.117 clip/s |
| NPU910B1 CPU16 / decoder4 / LPT / 复用元数据，精简ABBA候选中位 | 12.650 s | 7.905 clip/s |
| NPU最终独立入口，LPT | 12.775 s | 7.828 clip/s |
| NPU最终独立入口，FIFO | 19.530 s | 5.120 clip/s |

NPU精简ABBA A1/B1/B2/A2=47.394596 / 12.962440 / 12.337882 / 47.096970秒；
中位耗时降低73.22%，吞吐为原配置3.735倍。
与GPU历史最佳比是4.21倍左右的整机流水线吞吐，CPU架构、线程、并发和调度均不同，
**不能归因于NPU芯片计算快4.21倍；GPU尚未按同套新策略重测。**

计时为常驻模型、CPU池就绪和预热后的整批处理；含MP4读取/解码/缩放/进程传输/模型及同步，
NPU轮含可选精确校验。不含初始化、预热、NPU结果文件写出和退出；GPU历史轮有逐条日志写出。
OS页缓存未控制，不是冷启动、冷存储或HTTP SLA。

同冻结输入模型阶段100条：5090单条重放1.398秒，NPU单条2.795秒；包含传输、归一化和同步。
说明本轮整链路收益来自CPU供给和调度。四条合批预热协议不同，不给严格芯片比。

从CPU8×decoder2提升到16×4有RAM和CPU成本，每worker另设torch4线程，不等于固定占用64核。
精简ABBA两个候选轮PSS约34.13/53.59GiB；分配器缓冲、形状触达与池生命周期影响统计。
各轮结束NPU allocated=461544448字节。最终worker全部退出，所用NPU无计算进程、HBM回约3.4GB驱动基线。
RSS会重复统计共享页，PSS按秒采样可能漏掉短峰；短批既不能证明泄漏，也不能证明长期无泄漏。

## 逐项优化与回退

每项以上一步已保留配置为对照，两个配对均获胜、耗时中位降低至少2%、全部像素与分数精确一致才保留。
每轮同100条；逐项收益不能相加。

| 项目 | 对照→候选中位秒 | 降低 | 决策 |
|---|---|---:|---|
| CPU workers 8→16（先筛12/16） | 47.544→30.612 | 35.61% | 保留 |
| reader线程2→4 | 29.970→18.464 | 38.39% | 保留 |
| 离线长任务优先LPT | 18.004→12.099 | 32.80% | 保留 |
| 复用已解析容器时长 | 12.034→11.663 | 3.08% | 保留 |
| 原地归一化 | 11.664→11.549 | 0.98% | 回退 |
| 单clip Head无padding快路径 | 11.673→11.534 | 1.19% | 回退 |
| 常驻autocast | 11.757→11.641 | 0.99% | 回退 |

原模型数学路径不变；三个回退候选精度通过，但收益不足2%门槛，其实现不放入发布runtime。
共享内存IPC、额外双缓冲/异步H2D、自定义resize融合、attention替换和DVPP硬解没有引入，不能称为已验证。

## 最优NPU相对原GPU数值误差

同100条、300个输出；两边准备张量uint8 SHA256一致100/100。两端保留原FP32权重存储，
执行FP16 autocast，输入归一化和输出转换为FP32；并非BF16，也不是全部算子FP16。误差统计用FP64。

整体相对L2=0.1801714%，`sqrt(sum(error²)/sum(GPU_score²))`；R²=0.999991699。
MSE为分数平方单位，其余绝对误差为原始分数单位，不是百分比；整体行等权展开100×3个值。
没有做FP32基准对照、隐藏特征或逐层误差评估，不用近零分数的MAPE作为主指标。

## Timeline归因

优化前采集轮48.840秒，消费端等待44.333秒（90.77%）；该轮含profiler开销，不替换benchmark。
CPU累计阶段303.94秒是跨worker累计，不与墙钟相加：decode239.100秒/78.67%，
全分辨率float与除法30.826秒/10.14%，reader打开与元数据21.171秒/6.97%，
RGB复制7.604秒/2.50%，224 resize3.892秒/1.28%，其他1.347秒/0.44%。
平均活跃任务6.27/8，最后只有1–2个任务的累计时间10.12秒；LPT针对这一拖尾。
Host无profiler精简复测，等待43.864→8.976秒，模型调用及同步3.268→3.555秒。
H2D stream跨度约1.28ms/条、D2H约0.54ms/条，不是当前首要优化项。
原生trace含私有样本和路径，未上传；这里保留脱敏聚合，不能替代原trace逐事件审计。
